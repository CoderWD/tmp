========================================================================

This plain-text sample mirrors the PDF user guide in a lighter form.
It introduces Offline Ultra as an offline media player, file manager,
document downloader (direct links), and built-in multi-tab browser.

1. WELCOME TO OFFLINE ULTRA
---------------------------
Welcome to Offline Ultra — Media Browser. This sample document is bundled with the app so you can immediately see how Documents appear in your Downloads list and how the Files tab organizes ordinary files such as PDF and TXT.

Offline Ultra helps you keep media and documents on your iPhone or iPad, play them offline, organize playlists and folders, import from places you already trust (Files / iCloud, Photos, and local Wi‑Fi), and browse the web with a built‑in multi‑tab browser.

This guide deliberately focuses on features that help you manage YOUR content: files you own, files you created, files your organization shared with you, or files you obtained through legitimate means. Please respect copyright and the terms of service of any website or service you visit.

Tip: Open this PDF from Home → Downloads, or from the Files tab after first launch. The matching TXT sample shows the same ideas in plain text for quick reading on any device.


2. PRODUCT OVERVIEW (WHAT THIS APP IS FOR)
------------------------------------------
Offline Ultra is an offline‑first media and file companion:

• Local library: Keep audio, video, and documents on device for playback and preview without a constant network connection.

• Downloads list: Track completed downloads and open finished items from Home.

• Files manager: Browse folders, search, rename, move, and delete; import from iCloud Drive, Photos, or a computer on the same Wi‑Fi network.

• Playlists & favorites: Build music/video playlists, star favorites, and resume with a mini player.

• Built‑in browser: Open websites in multiple tabs, bookmark pages you care about, and use the address or search bar like a normal mobile browser.

• Playback extras: Lock‑screen controls, background audio, sleep timer, appearance themes, and optional app lock.

Important: Always download and import only content you have the right to use. Offline Ultra is a player and organizer — not a tool for bypassing protections or taking content without permission.


3. FIRST‑LAUNCH WALKTHROUGH
---------------------------
After installation you will see four main tabs along the bottom:

1) Home — library shortcuts, Downloads list, search in your local library, and settings entry.

2) Files — folder browser and import hub for documents and media already on your device or computer.

3) Browser — multi‑tab web browsing with bookmarks and a familiar toolbar.

4) Playlists — All Media, Favorites, Recently Played, and your custom playlists.

On first launch, Offline Ultra may seed a few sample items (such as short music tracks and this guide) so the Downloads and library areas never look empty. You can delete samples anytime; they are only helpers.

Suggested first steps (5 minutes):

• Play a sample track from Playlists → Music (or Home) to verify sound and lock‑screen controls.

• Open this PDF from Downloads to confirm document handling.

• Go to Files → Import and try pulling a photo or a document from Files / iCloud.

• Optionally start the local Wi‑Fi import page and upload a file from your computer’s browser.

• Open Browser, visit a site you normally use, and add a bookmark.


4. HOME TAB — DOWNLOADS, SEARCH, AND SHORTCUTS
----------------------------------------------
Home is your daily dashboard for local content.

Downloads list: Shows completed (and in‑progress) download items. Sample music and this user guide appear here after install so reviewers and new users can see that Offline Ultra stores ordinary documents as well as media. Tap an item to open or play it according to its type.

Add download (+): Paste a direct HTTP/HTTPS link to a file you are allowed to download — for example a public sample PDF, ZIP archive, spreadsheet, or other non‑restricted file hosted on a server you trust. The download manager saves the file into the appropriate local folder and lists it under Downloads / Files when finished.

Library search: Search titles already in your offline library. Results stay on‑device; they do not scrape third‑party catalogs.

Shortcuts: Jump into Files, Browser, Playlists, or Settings without digging through menus.

Mini player: When something is playing, a compact bar lets you pause, resume, or return to the full player from almost any screen.


5. FILES TAB — ORGANIZE WHAT IS ALREADY YOURS
---------------------------------------------
The Files tab is the backbone of Offline Ultra’s “offline utility” story. Think of it as a lightweight file manager tailored for media and documents.

Browse: Folders group content by type or by folders you create. Search filters long lists quickly.

Manage: Rename, move between folders, multi‑select delete, and open documents with the system preview where available.

Import from Files / iCloud: Use the system document picker to copy files from iCloud Drive, On My iPhone, third‑party file providers, or shared folders. This is the safest way to bring large libraries you already own into Offline Ultra.

Import from Photos: Bring videos or images from your photo library when you want them in the app’s folders for offline use or playlist building.

Import from computer (local Wi‑Fi): Start the in‑app local web server, open the shown URL on a computer connected to the same Wi‑Fi network, and upload files through the browser page. Ideal for moving lecture recordings, personal videos, ebooks, or office documents without cables.

After import, files appear under Files and — when applicable — become available to Playlists and the player.


6. DOWNLOADS — DIRECT LINKS TO ORDINARY FILES
---------------------------------------------
Offline Ultra can download files from a direct URL you paste yourself. This is useful for course materials, open documentation, software release ZIP files, PDF manuals, CSV exports, and similar assets published as plain downloadable links.

How to add a download:

1. From Home or Tasks, tap the add / download action.

2. Paste a full https://… link that points to the file itself (not merely a web page).

3. Confirm. Progress appears in the task / downloads UI; you can leave the app — background transfer continues when the system allows.

4. When complete, open the item from Downloads or locate it under Files.

Good candidates: PDF manuals, TXT readmes, ZIP of your own backups, Office documents shared via direct link by your school or workplace.

Please do not attempt to download material you do not have rights to. Follow copyright law and each site’s terms. If a site requires a licensed client or forbids bulk saving, use that site’s official tools instead.


7. BUILT‑IN BROWSER — TABS, BOOKMARKS, AND DISCOVERY OF INFORMATION
-------------------------------------------------------------------
The Browser tab is a multi‑tab WebKit browser for everyday browsing on the go.

Address & search bar: Enter a URL or a search query. Recommended sites may appear as shortcuts for popular destinations you choose to visit yourself.

Tabs: Open several pages at once, switch between them, and close ones you no longer need — similar to Safari’s tab overview patterns.

Bookmarks & recent: Star pages you revisit often; recent lists help you return without retyping.

Toolbar: Back, forward, reload, and new tab keep navigation familiar.

Site login when needed: Some websites require signing in. Offline Ultra can open a guided login flow so cookies are set for pages you are allowed to access with your own account.

Remember: The browser is for visiting the open web as you would in any mobile browser. Always obey the rules of the websites you visit and only save files you are permitted to keep.


8. PLAYLISTS, FAVORITES, AND LIBRARY STRUCTURE
----------------------------------------------
Playlists keep listening and watching organized without leaving the app.

System tiles: All Media, Shuffle All, Favorites, and Recently Played give one‑tap entry into your library.

Default Music / Video lists: Audio and video you add can be sorted into these collections; you may customize covers.

My Playlists: Create named lists, reorder, and switch between list and grid layouts with cover art.

Favorites: Star tracks or videos for a personal shortlist.

Covers: Prefer a custom image; otherwise the app may show the first media cover or a brand‑colored placeholder.

Home no longer stacks every “continue playing” widget on top; recent history lives under Playlists, while the mini player restores your last queue when available.


9. MEDIA PLAYER — OFFLINE FIRST
-------------------------------
The full‑screen player is built for reliability offline.

Transport: Play / pause, previous / next, scrub on the progress bar.

Repeat modes: List loop, single track loop, or shuffle.

Now Playing: Lock screen and Control Center / headset commands stay in sync via system Now Playing APIs so you can control playback without unlocking.

Background audio: Keep listening while browsing Files or using other apps (subject to iOS background policies).

Sleep timer: Fade out or stop after a chosen duration — useful at night.

Mini player: Continues across tabs so you never lose your place.

Format helpers: When needed, Offline Ultra can use on‑device conversion tools to normalize certain local media so they play more consistently. Conversion works on files already on your device.


10. SETTINGS — APPEARANCE, SECURITY, PREMIUM
--------------------------------------------
Appearance: Choose Light, Dark, or Follow System. Brand accents use a fresh teal aligned with the app icon and splash.

Typography: Adjust reading comfort where the app exposes font options.

App lock: Optionally protect entry with device authentication patterns supported by the security screen.

Premium / subscription: Unlock ad‑free and membership benefits described on the Premium page. Purchases use Apple’s standard StoreKit flow.

Privacy policy, Terms, About, and Rate Us: Standard storefront links and feedback paths live under Settings.

Ads (free tier): Non‑subscribers may see interstitial ads under the product’s frequency rules. New installs and certain reward periods can be ad‑free; Premium removes ads.


11. DETAILED FEATURE COOKBOOK
-----------------------------
A. Build a weekend offline pack

Import a folder of personal recordings via Wi‑Fi upload, create a playlist named “Weekend”, add items, enable shuffle, and set a sleep timer.

B. Study with PDFs

Download or import lecture PDFs (like this sample). Keep them under Files for Quick Look preview. Keep related audio notes in a Music playlist.

C. Family photo slideshow materials

Import preferred videos from Photos into Files, add them to a Video playlist, and play on a larger display with AirPlay / HDMI when your system supports it.

D. Travel mode

Before a flight, confirm Downloads completed, toggle appearance to Dark for cabin lighting, download any last TXT/PDF itineraries via direct links you own, and enable app lock if you share devices.

E. Cleanup day

Use Files search to find duplicates by name, multi‑select delete obsolete exports, and keep only current playlists. Sample media and guides can be removed once you are familiar with the UI.


12. ACCESSIBILITY AND EVERYDAY TIPS
-----------------------------------
• Prefer meaningful file names before import so search works better later.

• Keep large libraries on device storage with enough free space; iOS may purge caches under pressure, but your imported files in Offline Ultra’s directories persist until you delete them.

• Use descriptive playlist names (“Commute”, “Kids stories”, “Language practice”).

• When pasting download URLs, verify HTTPS and that the link ends with a real file extension when possible (.pdf, .txt, .zip, .docx, …).

• If a download fails, check network, URL expiry, and whether the server requires a login cookie — for authenticated portals, export the file to Files first, then import.

• Force‑quit rarely during active downloads; background sessions are more reliable if the system can finish the task.


13. PRIVACY, SAFETY, AND RESPONSIBLE USE
----------------------------------------
Offline Ultra stores media and documents locally on your device. Treat that storage like any personal folder: do not import confidential work files onto a shared iPad without an app lock.

The built‑in browser can access the open web. As with Safari, you are responsible for the sites you visit and the accounts you sign into.

Copyright & licensing: Only keep copies of works you created, that are licensed to you, that are in the public domain, or that a rights holder explicitly allows you to download. Do not use this app to infringe copyrighted streaming catalogs or to bypass technical protection measures.

Children: Follow Apple’s age rating guidance and family sharing practices if a child uses the device.

Feedback: If something is unclear in the UI, use Settings → Rate Us / feedback channels so we can improve labels and help screens.

15. APPENDIX — GLOSSARY
-----------------------

Mini player: Compact playback controls that persist across tabs.

16. APPENDIX — LONG‑FORM PRODUCT NARRATIVE
------------------------------------------
Offline Ultra exists because modern life still needs reliable offline pockets: flights, subways, classrooms with weak Wi‑Fi, kids’ devices with limited data plans, and field work away from the office. Streaming is wonderful when the network cooperates; Offline Ultra is for the hours when it does not.

Design‑wise the app keeps four jobs close: find information in a browser, bring files you already own into a private library, arrange them into playlists and folders, and play them with system‑grade controls. The Downloads list is the bridge between “I just saved something” and “I can find it again tomorrow.”

Sample music demonstrates playback immediately. This sample guide demonstrates that ordinary documents belong in the same workflow — download, store, open — without requiring you to understand advanced media tooling on day one.

As you grow into the app, lean on import paths first. Dragging your own library from a laptop over Wi‑Fi or selecting files from iCloud is usually faster and clearer than hunting for remote links. Direct URL download is there for the cases where a school portal or documentation site already published a clean file link.

Visual appearance matters on long trips: Dark Mode reduces glare; Light Mode stays crisp outdoors; Follow System keeps continuity with iOS. The teal brand color is intentional — calm enough for long listening, distinct enough to recognize in a sea of icons.

If you are evaluating Offline Ultra for a classroom, team, or family: start with a shared checklist — import a known PDF, play a short audio clip, create one playlist, bookmark one internal wiki page in the browser, and confirm app lock works on shared hardware. Those five checks cover the majority of daily needs.

Thank you for trying Offline Ultra. Whether you keep only this guide and a favorite album, or build a large personal archive, the goal is the same: your files, on your device, ready when the network is not.

Checklist — Import from iCloud / Files

□ Open Files tab → Import → choose Files / iCloud.

□ Select one or more items → confirm copy into Offline Ultra.

□ Verify they appear in the folder list and open correctly.



Checklist — Wi‑Fi computer upload

□ Phone and computer on the same Wi‑Fi.

□ Start import server in the app; note the URL.

□ On the computer browser, open the URL and upload.

□ Confirm completion in Files; stop the server when done.



Checklist — Direct document download

□ Obtain a legitimate direct file URL ending in a document extension.

□ Home / Downloads → add → paste URL → start.

□ Wait for 100% → open from Downloads or Files.



Checklist — Playlist evening

□ Playlists → create “Evening”.

□ Add several local audio items.

□ Set repeat or shuffle; optionally start sleep timer.

□ Lock the phone and confirm Control Center controls still work.
